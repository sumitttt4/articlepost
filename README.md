# Habit Tracker Hub

A monthly habit tracker that runs as a single static page (`index.html`).

- Add habits with a category and a monthly goal (days per month).
- Tick habits per day (Day view) or across the whole month (Month view).
- See completed vs goal, month %, daily progress chart, weekly progress, top habits and category totals.
- Everything saves automatically in the browser (localStorage). Use **Export backup** / **Import backup** to move data between devices.

Host it anywhere static, for example GitHub Pages (Settings → Pages → deploy from this branch, root folder).
